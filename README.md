# VoxEnhance AI

AI-powered voice enhancement web app.

## Features

- Voice clarity enhancement
- Noise reduction
- Warmth control
- Output volume control
- Audio upload
- Enhanced WAV download
- FastAPI backend
- FFmpeg audio processing

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Python
- FastAPI
- FFmpeg

## Project Structure

- index.html — Main website
- style.css — Website design
- script.js — Frontend functionality
- app.py — Backend API
- requirements.txt — Python dependencies
- Dockerfile — Backend deployment

## Important

GitHub Pages hosts the frontend. The Python backend needs separate hosting.
